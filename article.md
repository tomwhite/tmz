## Definitions and terminology

Let's start with some definitions and terminology.

### The Thue-Morse sequence

Let $T_i$ be the first $2^i$ terms in the Thue-Morse sequence. Then $T_0 = 0$, and for $i > 0$, $T_{i+1} = T_i \overline{T}_i$, where $\overline{T}_i$ is the negation of $T_i$, formed by interchanging 0's and 1's. So,

* $T_0 = 0$
* $T_1 = 01$
* $T_2 = 0110$
* $T_3 = 01101001$
* $T_4 = 0110100110010110$
* ...

There are other ways of defining the same sequence, for example individual terms in the sequence can be defined by via the recurrence relation:

$$
t_0 = 0\\
t_{2n} = t_n\\
t_{2n+1} = 1- t_n
$$

So $t_0 = 0$, $t_1 = 1$, $t_2 = 1$, $t_3 = 0$, $t_4 = 1$, ...

### Z-order curves

A Z-order curve is a space-filling curve, where the Z-value of a point which represents the (integral) distance along the curve is found by interleaving the binary coordinate values of the point.

## TMZ is a catalog of TM sequences

So we have generated a pleasing pattern, but what's interesting about it? Look at the top row of the pattern. It's just the Thue-Morse sequence!

For example, for the 4x4 pattern generated by $T_4$, the top row is $T_2$.

This is easy to prove by induction.

Consider the TMZ pattern for a square with side $2^k$. For $k=0$, the table is just a single entry $TMZ=0$, which is the same as the Thue-Morse sequence $T_0=0$.

For the inductive step, start with a square with side $2^k$. Because of the way that Z-order curves are constructed, for a square with a side which is a power of two, the curve is continued by a copy of itself to the right, with the last point on the original curve at the bottom right of the square, joined to the first point on the copy at the top left of the new square.

[TODO: diagram]

The values in the square are $T_{2k}$, and because of the way TMZ is constructed, the values in the copy of the square are the negation of $T_{2k}$.

[TODO: diagram]

Furthermore, since the Z-curve offsets in the top row of the first square are the same as the Z-curve offsets in the top row of the second square, it follows that the values in the top row of the second square are the negated values of the values in the top row of the first square. But this is just the recursive definition of the Thue-Morse sequence, hence the top row is the Thue-Morse sequence. QED
